# Image to SVG

A lightweight Python utility to convert raster images (JPEG, PNG) into scalable vector graphics (SVG) using color quantization and Run-Length Encoding (RLE).

## Features

- **Color Quantization**: Reduces the number of colors in your image to create a clean, stylized vector look.
- **Efficient SVG Generation**: Uses RLE (Run-Length Encoding) per row to minimize the number of SVG elements, keeping file sizes optimized.
- **Simple CLI**: Easy-to-use command-line interface for quick conversions.

## Prerequisites

This project uses [uv](https://github.com/astral-sh/uv) for dependency management and Python 3.13+.

## Installation

You can install the package directly using `uv`:

```bash
# Clone the repository
git clone https://github.com/bgregorutti/image-to-svg
cd image-to-svg

# Install the package and its dependencies
uv sync
```

## Usage

Once installed, you can use the image-to-svg command via uv run.

### Basic Conversion

To convert an image using the default color count (256 colors):

```bash
uv run image-to-svg --input path/to/your/image.png --output result.svg
```

### Advanced Configuration

You can specify the number of colors to use for quantization. A lower number will result in a more "pixel art" or stylized appearance.

```bash
# Convert with only 16 colors for a highly stylized effect
uv run image-to-svg --input input.jpg --output output.svg --colors 16
```

### Arguments

| Argument   | Description                                             | Default  |
| ---------- | ------------------------------------------------------- | -------- |
| `--input`  | Path to the input image (JPEG, JPG, or PNG)             | Required |
| `--output` | Desired output filename (saved in `outputs/` directory) | Required |
| `--colors` | Number of colors for quantization                       | 256      |

## How it Works

* Loading: The image is loaded using Pillow.
* Quantization: The image is converted to RGB and quantized to the specified number of colors.
* RLE Processing: The script iterates through each row of pixels, identifying continuous runs of the same color.
* SVG Construction: For each unique color, it groups all its horizontal segments into a single <g> (group) tag containing multiple <rect> elements. This significantly reduces the XML overhead compared to one rectangle per pixel.
